# Changelog

## 0.2.0 — Release candidate (2026-10-25)

- Added `doctor` environment diagnostics.
- Added user templates CLI and JSON-backed template storage.
- Added YAML output (`--format yaml`).
- Added `--enhance` with OpenAI-compatible, OpenAI, OpenRouter and Ollama adapters.
- Added optional FastAPI API and React + TypeScript web frontend.
- Added Windows setup and troubleshooting guide.
- Added CI workflows for Python tests and frontend build.

## 0.1.0

- Initial CLI with prompt profiles, interactive wizard, Markdown/plain/JSON output and clipboard support.
